## Testing record and restrictions

- `python -m unittest discover -p 'test_*.py' -v` executed against the supplied scripts in the assistant's container: **four tests passed**. The tests require neither CARLA nor CommonRoad and therefore test only pure-Python coordinate logic.
- There was **no demonstrated end-to-end CARLA 0.9.16 export / CommonRoad import run** in this audit.
- There was **no demonstrated CommonRoad `RPPSolver.plan()` execution**, map registration, lanelet construction, obstacle predictions, trajectory execution, or vehicle control.
- The conversion uses `(x, y) -> (x, -y)` and `yaw_degrees -> -yaw_radians` without origin alignment. This is not sufficient for converting a CARLA Town01 map into the previous CommonRoad scenario.
- The `InitialState` in `commonroad_import.py` captures a limited forward-driving state and does not fully represent a dynamic vehicle/actor trajectory, local offsets of obstacle shapes, or all simulation conditions.
- `README.txt` in the original archive did **not** include the references or creation record provided here. This omission is why this document was prepared.
